# Security policy

## Current status

This repository is a documentation and UI scaffold. It does not implement a cryptocurrency wallet, key storage, signing, or transfers. Do not use it to store secrets or handle real funds.

## Safe development

- Never commit private keys, seed phrases, wallet backups, API credentials, or signing secrets. Do not paste them into issues, pull requests, logs, or chat.
- Use test networks and valueless test assets only during development.
- Treat blockchain RPC endpoints and returned data as untrusted input.
- Do not claim security controls are implemented unless they have been built, tested, and reviewed.

## Reporting a vulnerability

Please do not publish exploitable details or secrets in a public issue. Contact the repository maintainer privately through the contact options on the GitHub profile to coordinate a responsible disclosure. No production wallet is currently provided by this repository.
