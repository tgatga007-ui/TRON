## Project status

This repository is currently documentation-only. It does **not** contain an Android wallet, key-management implementation, transaction signer, or working cryptocurrency transfer feature. Do not send funds or enter a recovery phrase based on this repository.

## Android wallet direction

The proposed product direction is a native Android, self-custody multi-wallet for Bitcoin (BTC), Ethereum (ETH), TRON (TRX), Litecoin (LTC), and Solana (SOL). The security requirements and implementation roadmap are documented in [Crypto security roadmap](docs/CRYPTO_SECURITY_ROADMAP.md). They are requirements, not claims that those protections or wallet features have already been implemented.

## Safety

Never commit or share private keys, seed phrases, wallet backups, or signing secrets. Do not use this repository to handle real funds until a working implementation has been independently reviewed and tested.
